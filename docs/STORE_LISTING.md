## 스크린샷 구성 (6.7" / 6.5" iPhone, Android 폰)

1. 홈 — "오늘도 한 단계 점프해볼까요?" (오늘의 목표 · 추천)
2. 코드 풀이 — 에디터 + 기호 툴바 ("4개 언어로 직접 풀고 바로 채점")
3. 채점 결과 — "정답입니다!" ("숨겨진 테스트까지 꼼꼼하게")
4. 코드 리뷰 퀴즈 — 문제 줄 표시 화면 ("실무 코드를 직접 리뷰")
5. 베스트 개선안 diff ("모범 리뷰와 개선안 비교")
6. 면접 카드 — 모범 답안 + 키워드 ("말하기 연습까지")
