# To Jump Programmer 개인정보 처리방침

> 앱 내 [마이 › 설정 › 개인정보 처리방침] 화면(`src/content/legal.ts`)과 같은 내용입니다.
> 웹 버전에서는 앱의 `/privacy` 화면이 공개 URL 역할을 합니다 (예: https://jump-programmer.github.io/to-jump-programmer/privacy). 스토어·AdSense 등록 시 이 주소를 입력하세요.

### 1. 수집하는 개인정보
To Jump Programmer(이하 "앱", 모바일 앱과 웹 버전을 포함합니다)는 회원가입 기능이 없으며, 이름·이메일·전화번호 등 개인을 직접 식별할 수 있는 정보를 수집하지 않습니다. 다만 앱을 무료로 운영하기 위해 광고를 표시하며, 이 과정에서 광고 사업자(Google)가 4항의 정보를 자동으로 수집할 수 있습니다.

### 2. 기기에 저장되는 정보
앱은 학습 기능 제공을 위해 다음 정보를 **사용자의 기기 안에만**(웹 버전은 브라우저 저장소에) 저장합니다. 이 정보는 운영자 서버로 전송되지 않습니다.

- 사용자가 입력한 닉네임, 학습 목표, 선호 언어·프레임워크
- 퀴즈 풀이 기록, 코딩 문제 제출 결과, 북마크, 작성 중인 코드
- 앱 설정(테마, 글자 크기, 코드 실행 서버 주소)

앱을 삭제하거나 [마이 › 설정 › 학습 기록 초기화]를 누르면 삭제됩니다. 웹 버전은 브라우저의 사이트 데이터를 지워도 삭제됩니다. 웹 버전의 [백업 내보내기]로 만든 파일은 사용자가 고른 위치에만 저장되며, 운영자에게 전송되지 않습니다.

### 3. 외부 통신
- **Python 실행 환경 다운로드**: Python 코드를 처음 실행할 때 공개 CDN(jsDelivr)에서 Pyodide 실행 파일을 내려받습니다. 이때 사용자 코드나 개인정보는 전송되지 않습니다.
- **원격 코드 실행 서버(선택)**: 사용자가 설정에서 직접 서버 주소를 입력한 경우에만, Java·Kotlin·C++ 채점을 위해 작성한 코드가 해당 서버로 전송됩니다. 이 서버는 사용자가 지정한 서버이며 운영자가 관리하지 않습니다.

### 4. 광고 (Google AdMob · Google AdSense)
모바일 앱은 Google LLC의 모바일 광고 서비스인 AdMob으로 배너 광고와 전면 광고를, 웹 버전은 Google AdSense로 화면 안의 광고를 표시합니다. 광고 제공·성과 측정·부정 클릭 방지를 위해 Google이 다음 정보를 수집할 수 있습니다.

- 광고 식별자: Android 광고 ID, iOS 광고 식별자(IDFA — '추적 허용'에 동의한 경우에만), 웹 버전에서는 쿠키 등 브라우저에 저장되는 식별자
- 기기·앱 정보: 기기 모델, 운영체제 버전, 언어 설정, 앱 버전(웹 버전은 브라우저 종류와 방문한 페이지 주소)
- IP 주소와 이를 바탕으로 추정한 대략적인 위치
- 광고 노출·클릭 기록, 오류·성능 진단 정보

| 구분 | 내용 |
| --- | --- |
| 이전받는 자 | Google LLC (미국) |
| 이전 시점·방법 | 광고를 불러올 때 네트워크로 전송 |
| 이용 목적 | 광고 제공 및 성과 측정, 맞춤형 광고(동의한 경우), 부정 트래픽 방지 |
| 보유 기간 | Google의 개인정보처리방침에 따름 |

운영자는 이 정보를 직접 수집하거나 열람하지 않습니다. Google의 정보 이용 방식은 https://policies.google.com/technologies/partner-sites 에서 확인할 수 있습니다.

**맞춤형 광고를 원하지 않는 경우**
- iOS: 앱에서 표시되는 '추적 허용' 요청을 거부하거나, [설정 › 개인정보 보호 및 보안 › 추적]에서 언제든 끌 수 있습니다.
- Android: [설정 › 개인정보 보호 › 광고] (기기에 따라 [설정 › Google › 광고])에서 광고 ID를 삭제하거나 재설정할 수 있습니다.
- 웹 버전: Google 내 광고 센터(https://myadcenter.google.com)에서 맞춤 광고를 끄거나, 브라우저 설정에서 쿠키를 차단·삭제할 수 있습니다.
- 유럽경제지역(EEA)·영국·스위스: 앱 실행 시(웹 버전은 사이트 방문 시) 표시되는 동의 화면이나 [마이 › 설정 › 광고 개인정보 설정](웹 버전은 화면에 표시되는 개인정보 설정 링크)에서 선택을 바꿀 수 있습니다.

맞춤형 광고를 거부해도 모든 학습 기능을 그대로 이용할 수 있으며, 이 경우 일반(비맞춤형) 광고가 표시됩니다.

### 5. 제3자 제공
운영자는 개인정보를 제3자에게 제공하지 않습니다. 4항의 광고 관련 정보는 Google이 직접 수집하며, 앱에는 분석(애널리틱스) SDK가 포함되어 있지 않습니다.
